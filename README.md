# alx-capstone

💱 Currency Converter App
A modern, real-time currency conversion application built with React, JavaScript, and Tailwind CSS. This project demonstrates API integration, responsive UI design, and dynamic state management.

🚀 Features
Live Exchange Rates: Integrates with ExchangeRate-API for real-time data.

Instant Conversion: Updates the result dynamically as the user inputs values.

Currency Toggle: A dedicated "Swap" feature to flip base and target currencies.

Mobile-First Design: Built with Tailwind CSS for a fully responsive experience across all devices.

Clean UI: A minimalist, user-friendly interface focused on speed and clarity.

🛠️ Tech Stack
Framework: React.js (Functional Components & Hooks)

Styling: Tailwind CSS (Utility-first CSS)

Logic: JavaScript (ES6+)

API: ExchangeRate-API

Build Tool: Vite (for a fast development environment)

Deployment: Vercel or Netlify
